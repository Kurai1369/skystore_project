# 🛒 SkyStore — Учебный проект интернет-магазина

> Домашнее задание по курсу «Python-разработчик». Базовое веб-приложение на Django с каталогом и формой обратной связи.

## ✨ Функциональность
- 📦 **Главная страница**: витрина с описанием проекта и карточкой товара
- 📞 **Страница контактов**: реквизиты компании + форма обратной связи
- 📤 **Обработка форм**: приём `POST`-запросов, вывод данных в консоль, сообщение об успехе
- 📱 **Адаптивность**: вёрстка на Bootstrap 5.3
- 🌿 **GitFlow**: структура веток `main` → `develop` → `feature/homework_XX`

## 🛠 Технологический стек
| Инструмент | Версия | Назначение |
|------------|--------|------------|
| Python | 3.10+ | Язык разработки |
| Django | 4.2+ | Веб-фреймворк |

## 🚀 Быстрый старт

### 1. Клонирование и подготовка
```bash
git clone https://github.com/ВАШ_НИКНЕЙМ/skystore_project.git
cd skystore_project
```

### 2. Виртуальное окружение
#### Windows
```bash
python -m venv venv
venv\Scripts\activate
```
#### macOS/Linux
```bash
python3 -m venv venv
source venv/bin/activate
```
### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```
### 4. Запуск сервера
```bash
python manage.py runserver
```
